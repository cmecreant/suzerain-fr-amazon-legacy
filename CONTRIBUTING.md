# Contribuer

Les corrections de compatibilité, de documentation et d'installation sont les bienvenues.

N'ajoutez pas de fichiers du jeu ni de textes de traduction sans autorisation explicite. Pour signaler un texte restant en anglais, joignez le nom de l'écran, une capture si possible, le chapitre concerné et les lignes pertinentes de `MelonLoader/Latest.log`.

Avant de proposer une modification :

1. compilez avec `scripts/build.ps1` ;
2. lancez la version Amazon de Suzerain ;
3. vérifiez le menu principal puis une partie existante ;
4. confirmez qu'aucune erreur nouvelle n'apparaît dans le journal MelonLoader.
