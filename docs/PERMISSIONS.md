# Autorisation de redistribution

Le projet de traduction amont ne présente pas de fichier de licence explicite. Avant de publier une archive contenant ses textes ou ses fichiers, demandez une autorisation écrite à son auteur.

Message proposé :

> Bonjour,
>
> J'ai préparé une couche de compatibilité permettant d'utiliser votre traduction française de Suzerain avec l'ancienne version Amazon Games (`2.0_release_0.6`).
>
> Puis-je publier gratuitement sur GitHub une archive comprenant vos fichiers de traduction et `SuzerainTrad.dll`, avec un crédit visible et un lien vers votre dépôt ? Le code de compatibilité serait publié séparément sous licence MIT et aucun fichier original du jeu ne serait inclus.
>
> Si vous préférez, je peux également publier uniquement l'adaptateur et renvoyer les utilisateurs vers votre installateur.

Conservez la réponse avec les documents du projet et indiquez précisément la portée de l'autorisation dans les notes de publication.
